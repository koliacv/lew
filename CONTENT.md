# Матеріали та формат питань

База містить 200 авторських навчальних питань, тематично пов'язаних із наданими користувачем матеріалами. Це не дослівне відтворення офіційного тесту та не повне перетворення кожного абзацу файлів на питання.

## Вихідні матеріали

- 07 LEW 16.05.2024(2).pdf
- LEW 06.11.2024(1).pdf
- 08 LEW 06.11.2024 (1)(1).docx
- LEW 11.2025(1).pdf
- LEW - 26.05.2026(1).pdf
- Конспект полный.pdf
- Choroby_Zespoły(2).docx
- Ważne nazwiska w chirurgii(1).doc
- skale_i_klasyfikacje(1).docx
- LEK TOP100 Skale.docx — спільні з LEW теми

PDF і DOCX за листопад 2024 мають значне тематичне перекриття. Посилання `src` вказує на навчальний матеріал за темою, а не означає дослівне цитування чи офіційне підтвердження ключа. Вихідні файли не включені до публічного репозиторію.

## Формат `data/questions.json`

| Поле | Зміст |
| --- | --- |
| `id` | Унікальне ціле число |
| `topic` | Назва теми польською |
| `q` | Питання польською |
| `opts` | П'ять різних відповідей; **перша, індекс 0, правильна** |
| `pl` | Коротке пояснення польською |
| `ua` | Пояснення українською |
| `steps` | Три кроки анімованої карти пам'яті |
| `src` | Індекс матеріалу в `data/sources.json` |

Інтерфейс перемішує порядок показу варіантів, але зберігає індекс вихідного варіанта для оцінювання. Не змінюй порядок `opts` без перевірки правильного ключа. Усі питання одновибіркові.

При оновленні запускай `npm test` і `npm run build`. Поточна валідація вимагає 200 питань у 10 темах по 20; якщо змінюєш розмір бази, узгоджено онови валідацію, написи в інтерфейсі й правила вибірки пробного іспиту.

## Поведінка сесії

Навчання не має таймера. Для тесту застосовується 72 секунди на питання (200 питань = 4 години). Під час тесту правильність не показується; відповіді можна змінювати до завершення. Після закінчення часу сесія автоматично завершується. Помилки й пропуски дають 0 балів. Поріг визначається за точним співвідношенням, а не округленим відсотком. Повторення помилок запускає нову сесію навчання.

Анімації — мнемонічні карти з трьох кроків, не медичні симуляції. Переклад пояснення доступний у режимі навчання після перевірки та під час розбору завершеного тесту. Питання й варіанти залишаються польською.
