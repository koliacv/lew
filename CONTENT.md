# Матеріали та формат питань

База містить **514 питань**: 500 авторських адаптацій та 14 перенесених або уточнених питань із наданих матеріалів. **Повне покриття всіх матеріалів не підтверджено.**

## Аудит від 3 листопада 2026

Перевірено структуру всіх 11 наданих файлів: 982 сторінки PDF, абзаци й таблиці Word. Для конспекту додатково виконано OCR усіх 142 сторінок. Загальний індекс містить 2075 одиниць: сторінки, абзаци, рядки таблиць та кандидати питань. Це не 2075 тестів і не клінічна рецензія 2075 тверджень.

Звіт: [audit.html](audit.html). Інвентаризація з SHA-256: [data/source-audit.json](data/source-audit.json). Повний текст і робоча черга перевірки збережені локально поза публічним репозиторієм. Вихідні документи та текст підручника не публікуються.

Структурний аналіз охоплює всі файли. Ручна семантична та клінічна перевірка всього корпусу не завершена. Лексичні збіги використовуються лише для пошуку кандидатів, а не для оголошення теми покритою. У підручнику з акушерства 747 сторінок; його не можна вважати охопленим на підставі кількості питань у темі.

## Перенесені питання

- ID 501–504: `LEW 11.2025.pdf`, PDF с. 1, записи 2, 5, 6, 14. Формулювання й набір варіантів збережено, нормалізовано пробіли. Позначений у матеріалі ключ перевірено за посиланнями в `references`.
- ID 505: конспект, PDF с. 80, питання про RKO немовляти. Варіанти збережено. Умову про підготовку рятувальника уточнено за ERC/RCUK 2025, оскільки без неї вибір між 15:2 і 30:2 неоднозначний. Оригінал показується в поясненні.
- ID 506–511: LEW 11.2025, записи 3, 8, 168, 175, 197, 154. Додано позначені переклади й уточнення. Збережено саме записані 3–5 варіантів, без дописування відсутніх. Якщо автор не позначив ключ однозначно, його встановлення за зовнішнім клінічним джерелом прямо описано в `answerEvidence`.
- ID 512: LEW 16.05.2024, с. 7, профілактика вітаміну D у доношеного новонародженого. ID 513–514: LEW 26.05.2026, с. 16 і 11, механізм метформіну та тест Сперлінга. Збережено відповідно 5, 4 і 2 варіанти.
- Виділена відповідь у спогадах учасників не є офіційним ключем CEM. Дискусійні, неповні та контекстно залежні записи не імпортуються автоматично.

У звіті окремо наведено чотири перевірені помилки вихідних матеріалів: прирівнювання GCS 3 до смерті мозку, одиниці дози стероїду, трактування qSOFA та суперечливий каріотип Тернера. Це не повний перелік помилок корпусу. Для 177 із 181 номерованих записів Word за 06.11.2024 знайдено відповідний початок заголовка у PDF за ту саму дату; ці файли значною мірою дублюються.

Перенесені питання можна відкрити кнопкою «Powtórz pytania z materiałów». Формат відповіді та пояснення такий самий, як у тематичній сесії; новий режим оцінювання не введено.

## Формат даних

`data/questions.json`: `id`, `topic`, `q`, `opts` (5 варіантів для авторських питань, 2–5 збережених варіантів для питань із джерел; правильний має індекс 0), `pl`, `ua`, `steps` (3 опорні слова), `src`, `sourceRef`, необов’язкові `references`.

Для питань із джерел обов’язковий `provenance`: тип перенесення, назва та SHA-256 файлу, PDF-сторінка, номер запису, оригінальне питання, початковий порядок варіантів, індекс позначеної відповіді, спосіб її позначення та нормалізація. Валідація перевіряє збереження набору варіантів і правильного ключа після перестановки.

Для перекладених варіантів `translatedOptions` зберігає той самий порядок, що й `originalOptions`; `correctOriginalIndex` посилається на обидва масиви. `adaptationNote` пояснює зміну. Сесія перемішує лише фактично наявні варіанти, не створюючи порожніх або вигаданих відповідей.

## Тренування

Одна відповідь → «Odpowiedz» → негайні результат, час, польське пояснення, примітка для запам’ятовування та візуальна підказка. Український переклад і повний атлас згорнуті. Ціль 70 секунд не блокує відповідь. Відповіді та результати не зберігаються між сесіями.

Випадковий добір насамперед використовує непереглянуті питання, далі відкладає нещодавно показані й пріоритезує найрідше та найдалі переглянуті. Історія за ID зберігається локально. Авторська адаптація та перенесений варіант одного клінічного сюжету мають різні ID; семантичне дублювання не виключається.

10 тем містять щонайменше 50 питань кожна. Пробний LEW обирає по 20 із кожної теми, разом 200. Ці пропорції навчальні, не офіційні.

## Перевірки

`npm test` та `npm run build`. Підтвердження повного тематичного покриття потребує завершення ручної черги зіставлення та рецензії ключів; автоматичні тести перевіряють структуру й поведінку сайту, а не медичну правильність усієї бази.
